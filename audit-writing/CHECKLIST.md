# Draft checklist

Fill this before handing over the prose. A blank item is a fail. Do not treat the checklist as a place to add findings.

## Setup

- [ ] Read Writing-DNA.md, language-dna.md, structure-patterns.md, cognitive-framework.md, and visual-style-guide.md in this turn.
- [ ] article_type named: experiment, archival, field, or review.
- [ ] Five papers selected with select_papers.py, or from CATALOG.md if raw/ is unmounted. Each line says match or fill, the date, and the title.
- [ ] Shared cadence stated from those five, in a few lines, before the prose.
- [ ] Full text was read, or the reply says it was unavailable. No invented stand-in papers.

## Claims

- [ ] Every factual claim in the draft is in the assignment. No mean, path coefficient, participant pool, or stimulus from the corpus.
- [ ] No byline from the catalog. The draft is not written as one of those authors.
- [ ] The result names a condition. A main effect is not the contribution.
- [ ] Positive and negative cells are not mirrored unless the assignment's theory signed both.
- [ ] A mechanism the assignment did not test is hedged with "may" or "likely," or it is reported as the assignment stated it, without a stronger verb.
- [ ] If the mechanism has no citation, it stays uncited and this box notes that. A citation is not invented.

## Sentences

- [ ] First person plural, or "I" only because the assignment said single-authored. Not both.
- [ ] "Participants" in a new paper. "Subjects" only if the assignment is matching a pre-2000 voice on purpose.
- [ ] Median sentence near 22 words. One long comparison sentence is allowed. Short sentences are not stacked.
- [ ] The dependent variable keeps its name. It is not replaced with "this outcome."
- [ ] Result verbs are "find" or "show." Theory verbs are "suggest" or "predict." "Associated with" only in an archival result or a citation of one.
- [ ] No "importantly," no "very," no exclamation point in the body, no rhetorical question, no bold sentence in the argument.

## Venue and close

- [ ] MEMORY.md was read. Venue is named, or the unnamed-venue default is named in the reply.
- [ ] One citation convention for the whole piece. Brackets, ampersands, and comma-before-year are not mixed.
- [ ] The last move names a reader or a decision the result changes. It does not say the topic is important.
- [ ] Limitations, if any, each name the next design. They do not apologize.

## Second pass

- [ ] lieflat-less-ai-tone has been applied in a separate turn, or this draft is marked "not yet cleaned."
- [ ] Where a tell-rule conflicted with the DNA, the DNA was kept, and the conflict is named here.
